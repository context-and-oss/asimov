Subagents

The four Accelerate roles — Giskard and Daneel build, Calvin tests, Baley reviews — each a role-* skill carrying the whole method plus a thin shell per harness (Claude Code, Codex). All read the active repo's conventions at run-time and flag instead of guessing.

Artifact maturity

Every artifact carries one level — assess, trial, adopt or hold — in a YAML block at the top of its definition. The producing command prints it as one chat line; a maintainer moves it on evidence of use, never on time.

features/D101-artifact-maturity.html
Named for Asimov's robots — every agent has one job and a law it won't break. Baley reviews but never edits; Calvin tests but never ships production code.
