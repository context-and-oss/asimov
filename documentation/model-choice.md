# Model choice — retired 2026-09-29

Asimov names no model. Skills and subagents run on the model the developer's session runs on, in Claude Code and in Codex alike; the plugin carries no `model` or `effort` field anywhere. Design: [`features/D101-codex-support.html`](features/D101-codex-support.html) (R6, the no-model rule) and D100 §7.3.

Routing a delegation to a smaller or larger model by written criteria, and logging what ran, is proposal [#7](https://github.com/context-and-oss/asimov/issues/7).

This file stays so that older links resolve; it carries no mapping.
