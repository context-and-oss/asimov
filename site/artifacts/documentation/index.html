Maturity

Every artifact, here and under General, carries one level from the technology radar. It tells you how far to trust the shape before you build on it.

LevelWhat it means for you
assessA proposal. Nothing outside the Asimov repo has used it yet. Use it, and expect the shape to move.
trialOne artifact of this kind has been reviewed by someone other than its author. The shape held once.
adoptUsed in a second repository and revised at least once because of that use. Build on it.
holdDo not start new work on it. It is being replaced or withdrawn.
plannedNot built. No definition, template or command yet.
  • Levels move on evidence, never on time. A maintainer promotes an artifact when the evidence exists, and names it in the commit.
  • Rewriting the bar drops it back to assess. A new shape has to earn trust again.
  • The command tells you. When a command produces an artifact below adopt, it prints the level as one line before its first question.
  • Every page here shows it. The chip next to an artifact's name is the level from its definition, checked at each release.
