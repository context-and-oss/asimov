Why

Code arrives faster than it can be reviewed, and the reasons behind it get lost.

What goes wrong at L2

  • More code than the team can review.
  • Design decisions made in a conversation, lost when it closes.
  • The AI guesses your house style, and guesses differently each time.

More upfront work

To make AI do more work, humans must do more upfront work.

The total thinking does not decrease. The typing moves from code to specification, and the skill from how to build to how to describe.

The design has to be complete

At L3 an agent builds from a written design, so the design has to be complete enough that the agent never has to ask. That is a higher bar than most design docs meet. Asimov gives the feature design (D101) a definition with two bars, and a review that says what is still missing.

Why HTML

  • Word is good for people, bad for agents. Binary, no diff, the structure is invisible to the model.
  • Markdown is good for agents, bad for people. Diffable and readable by a model, but flat, with no visual shape an approver can navigate.
  • HTML is good for both. One self-contained file that renders for the approver and parses for the agent, kept in git next to the code. That is why every design is an HTML page.

The argument owes a debt to Thariq Shihipar's The unreasonable effectiveness of HTML (Anthropic, 2026-05-20): past a hundred lines, markdown stops being readable, and HTML lets the structure be seen.

Four rules

  • No technology before the business signs. The design command stops after the business design.
  • The reviewer is never the author. The gap-free verdict is a person's, and not the writer's.
  • Agents read your rules, they do not carry a copy. Conventions are read from your repo at run time.
  • No command approves anything on its own. Approvals stay with people, four times: the design twice, the plan, the pull request. The plan's is the one a command writes down, on your word at the cut.

What you keep

The plugin is prompt files, templates and definitions, with nothing to host and no service in the path. Every design, persona and plan lands in your repository as files you can read and edit. Walk away and you keep every document.
