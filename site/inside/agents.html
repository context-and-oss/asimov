Your conventions are read at run time, never replaced.

  • An agent is a subagent — a worker you hand a task to. Its method is a skill; the agent file is a thin shell per tool (Claude Code today, Codex as a prototype). The roles are planner, builder, tester and reviewer; planner is reserved. Today: two builders, one tester, one reviewer.
  • Convention files are read by path when the agent runs. There is no copy to drift.
  • A missing or contradicted convention is flagged, not filled in with a default.
  • Baley's read-only boundary is enforced by its tool grant. The builders' boundaries are instructions, not a tool grant — stated plainly.
  • A builder for another stack is the same method with a different convention list.

Named for Asimov's robots: one job each, and a law it won't break.
