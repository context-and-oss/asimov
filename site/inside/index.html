What's inside

Commands, artifacts, personas, agents, and the model an engagement runs on. Click any box to read about it.

Key Yours: you and your repository Asimov writes Asimov reads, then reviews or builds The frame around the work → opens the page
  • Everything lives in your repository. Commands write into it; personas and agents read from it. There is no copy inside the plugin to drift.
  • Only the commands write. Personas hand back where they stopped reading; agents hand back code, tests and findings. The decisions stay yours.
  • The frame is not a step. Project management is the engagement around the feature work; the artifacts it needs, a risk log among them, land in the repository later.
