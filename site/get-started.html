Get started

An afternoon to install and wire up a repo, and a first feature through design and spec the same week.

Supported

  • Coding agents: Claude Code, and Codex for the setup, the Design stage and the Spec stage. Nothing has been run in Codex yet.
  • Software stacks: C#/.NET and TypeScript/Angular. Tests in .NET.

Install

Claude Code

/plugin marketplace add context-and-oss/asimov
/plugin install asimov-plugin
  • Update later with /plugin marketplace update asimov-marketplace. No auto-update.
  • Versions are major-only. Any release may change a bar or a template, so read the release notes before updating a repo with designs in flight.
  • Needs access to the models the commands pin, mapped in model-choice.md.

Codex

codex plugin marketplace add context-and-oss/asimov
codex plugin add asimov-plugin@asimov-marketplace
  • Update with codex plugin marketplace upgrade asimov-marketplace, then start a new session.
  • Codex loads the plugin's skills, not its slash commands. Set a repo up with $asimov-plugin:codex-asimov-init; plan a feature with $asimov-plugin:asimov-spec. Design a feature with $asimov-plugin:asimov-design and review it with $asimov-plugin:asimov-design-review; only asimov-init is Claude Code only.

Make it yours

  • artifact-persona-authoring captures your real approver as a persona in ten minutes. Every design from then on is read as them before they see it.
  • It shows who is on the roster first, standard and custom.
  • When a command produces an artifact below adopt, it prints the level as one line before its first question. Say so to the team.

A first step that proves something

Pick one team and one real feature. Take it through design, spec and the agents. Count the clarifications asked during coding, before and after.
